# HardlyWorld — сайт правил

Единый React/Vite-сайт для Minecraft-проекта с правилами сервера и списком разрешённых/запрещённых модов.

## Что внутри
- Главная секция в тёмном стиле, ориентированном на референс WarpTime.
- Раздел правил с категориями, наказаниями и раскрывающимися примечаниями.
- Раздел модов с вкладками «Все / Разрешённые / Запрещённые».
- Поиск по модификациям.
- Адаптивная мобильная навигация.
- Кнопка копирования IP.
- Ссылки на VK, Discord и магазин.

## Перед публикацией
Откройте `src/App.tsx` и замените значения в верхней части файла:

- `SERVER_IP` — реальный IP/домен Minecraft-сервера.
- `DISCORD_URL` — ссылка на Discord.
- `VK_URL` — ссылка на VK.
- `STORE_URL` — ссылка на магазин.

## Запуск

```bash
npm install
npm run dev
```

Сборка для публикации:

```bash
npm run build
```
