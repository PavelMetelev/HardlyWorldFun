# HardlyWorld — сайт правил

Единый React/Vite-сайт для Minecraft-проекта с правилами сервера и списком разрешённых/запрещённых модов.

## Возможности

- Главный экран со статусом Minecraft-сервера, онлайном и версией.
- Копирование IP и быстрые ссылки на магазин и VK.
- Поиск по правилам с подсветкой совпадений.
- Фильтрация правил по типу наказания.
- Прямые ссылки на отдельные пункты правил.
- Поиск модификаций с точным результатом «Разрешён / Запрещён».
- Сворачивание категорий и копирование найденного списка модов.
- Адаптивная навигация и кнопка возврата наверх.
- SEO-метаданные для поисковиков и социальных сетей.
- Автоматическая GitHub Actions-проверка production-сборки.

## Структура

- `src/App.tsx` — интерфейс и интерактивность.
- `src/data.tsx` — правила, модификации и настройки проекта.
- `src/index.css` — базовые стили и accessibility-настройки.

## Настройка

Основные значения находятся в `src/data.tsx`:

- `SERVER_IP` — IP/домен Minecraft-сервера.
- `VK_URL` — ссылка на VK.
- `STORE_URL` — ссылка на магазин.

Статус сервера запрашивается через Minecraft Server Status API. Сервис поддерживает Java Minecraft и возвращает онлайн/оффлайн, игроков и версию; ответы кэшируются примерно на 5 минут. citeturn455056search0
